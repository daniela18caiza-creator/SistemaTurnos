
# Sistema de Gestión de Turnos - Dispensario Médico

## Descripción

Aplicación web diseñada para organizar la atención de pacientes
en un dispensario médico mediante un sistema de turnos.

## Objetivo

Facilitar el registro de pacientes, generar números de atención
y organizar la lista de espera.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub

## Funcionalidades

- Registro de pacientes por nombre.
- Generación automática de números de turno.
- Visualización del turno en atención.
- Lista de pacientes pendientes.
- Conteo de turnos en espera.
- Llamado del siguiente paciente.
- Diseño adaptable a celulares y computadoras.

## Cómo ejecutar

1. Descargar o abrir la carpeta SistemaTurno.
2. Abrir el archivo index.html.
3. Ejecutar el archivo en Google Chrome o cualquier navegador.
