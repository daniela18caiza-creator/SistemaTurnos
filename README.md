
# Sistema de Gestión de Turnos

## Descripción
Aplicación web para gestionar los turnos de los pacientes de una clínica o centro universitario.

## Objetivo
Facilitar la organización de los turnos y reducir el tiempo de espera.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Visual Studio Code
- GitHub

## Funcionalidades
- Solicitar turnos.
- Generar números automáticamente.
- Mostrar turnos pendientes.
- Llamar al siguiente paciente.
- Actualizar los turnos pendientes.

## Cómo ejecutar
1. Abrir la carpeta SistemaTurnos.
2. Abrir el archivo index.html.
3. Ejecutarlo en Google Chrome o cualquier navegador.
